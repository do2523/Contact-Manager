This is a contact manager webapp designed for COP4331. It consists of a login and register page 
to allow users to login or create a new account. Once logged in the app displays all the users 
contacts and the contact information as well as allowing users to add new contacts and delete old contacts.

It was designed implemented and tested on a LAMP architecture, that is using Linux Ubuntu specifically 
as the base OS with Apache as the webserver, MySQL as the database management system, and php as the API 
language. For the front end JavaScript, CSS, and HTML were used as well.
